# 🚀 Quick Start Guide

## ⚡ Cài đặt nhanh (3 bước)

### 1️⃣ Cài đặt dependencies
```bash
pip install -r requirements.txt
```

### 2️⃣ Chạy setup (Khuyến nghị)
```bash
python setup.py
```
Script này sẽ:
- ✅ Kiểm tra cấu trúc thư mục
- ✅ Tạo thư mục cần thiết
- ✅ Kiểm tra dependencies
- ✅ Test feature extraction

### 3️⃣ Chạy app
```bash
python app.py
```

Truy cập: **http://localhost:5000**

## 🎯 Test nhanh

### Upload ảnh đầu tiên
1. Vào trang **Thư viện**
2. Click **"Tải ảnh lên"**
3. Chọn 5-10 ảnh
4. Đợi xử lý (mỗi ảnh ~0.5s với config tối ưu)

### Truy vấn
1. Vào trang **Truy vấn Ảnh**
2. Upload 1 ảnh mẫu
3. Xem top-10 kết quả tương tự

### So sánh
1. Vào trang **So sánh**
2. Upload 2 ảnh
3. Xem điểm tương đồng

## 🐛 Gặp lỗi?

### ❌ Error: `TemplateNotFound: 404.html`
**Đã fix!** - Không cần file 404.html nữa

### ❌ Upload quá chậm
**Solution 1:** Đã tối ưu - Bây giờ nhanh gấp 10 lần!

**Solution 2:** Nếu vẫn chậm, edit `config.py`:
```python
MAX_IMAGE_SIZE = (128, 128)  # Giảm từ (256, 256)
```

### ❌ `ModuleNotFoundError: No module named 'services'`
```bash
# Tạo file __init__.py
touch services/__init__.py
# Hoặc
python setup.py
```

### ❌ `ImportError: No module named 'cv2'`
```bash
pip install opencv-python
```

## ❓ FAQs

**Q: Tại sao phải dùng `features_optimized.py`?**
A: Nhanh hơn 10 lần! Vẫn giữ nguyên logic, chỉ tối ưu parameters.

**Q: Có thể dùng LBP 24-point không?**
A: Có! Dùng `lbp.py` thay vì `lbp_optimized.py`. Chậm hơn nhưng chính xác hơn.

**Q: Database lưu ở đâu?**
A: `image_database.pkl` (pickle file) và `metadata.json`

**Q: Làm sao xóa database?**
A: Click nút "Xóa" màu đỏ ở Thư viện, hoặc xóa file `.pkl`
